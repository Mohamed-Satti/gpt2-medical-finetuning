# Data Directory

This directory is intended to store the datasets used in this project.
Note that large data files are ignored by version control.

The following files are generated by the notebook:
- `pretrain.txt`: Medical abstracts for continued pre-training.
- `classification.csv`: Labeled dataset for sequence classification.
- `instruct.json`: Instruction-response pairs for assistant tuning.
- `general_sentences.txt`: Source of chit-chat data.
